# قوانین سختگیرانه پروژه (همیشه رعایت شود)

## منبع حقیقت
1. تنها منبع حقیقت برای API فایل `docs/backend-api.md` است. هیچ endpoint، فیلد، enum یا نقشی که در آن سند نیست نباید ساخته یا فرض شود.
2. اگر UI فیلدی نیاز دارد که API ندارد: آن بخش را با حالت خالی (empty state / "—" / پنهان) رندر کن و یک خط در `docs/BACKEND_GAPS.md` اضافه کن. هرگز داده خودت را جایگزین نکن.

## ممنوعیت داده تستی (مهمترین قانون)
3. هیچ داده mock / sample / seed / placeholder جدیدی به کد برنامه اضافه نکن. شامل: آرایه ثابت سازه، رزرو، کاربر، شهر، استان، آمار (مثل ۱٬۵۲۰ سازه)، متن نمونه، تصویر نمونه، و fallback وقتی API خطا میدهد.
4. وقتی API خطا داد یا داده نداشت: Loading / Error / Empty واقعی نشان بده، نه داده جعلی.
5. داده تستی فقط داخل پوشه tests/ یا __fixtures__/ مجاز است و هرگز از کد برنامه import نمیشود.
6. اگر در حین کار به فایل mock موجود برخوردی که خارج از تسک جاری است، دست نزن؛ فقط در گزارش بنویس.

## قراردادهای فنی
7. پول: API همیشه «ریال». UI همیشه «تومان». تبدیل فقط در `shared/lib/money.ts` (ورودی کاربر به تومان → ×۱۰ هنگام ارسال؛ پاسخ API → ÷۱۰ هنگام نمایش). مبالغ در پاسخ API رشته‌اند.
8. تاریخ: API و فرمها میلادی ISO 8601. تبدیل به شمسی فقط در لایه نمایش (`shared/lib/dates.ts`).
9. توکن احراز هویت فقط در کوکی HttpOnly. هرگز در localStorage/sessionStorage/کوکی قابل‌خواندن توسط JS.
10. وضعیت رزرو در API شکل `{ value, label }` دارد. دکمه‌های عملیات فقط با `allowed_actions` رندر می‌شوند؛ ماشین وضعیت در فرانت بازتولید نشود.
11. در درخواست‌های FormData هدر Content-Type دستی ست نشود.
12. تمام فراخوانی شبکه فقط از طریق `shared/lib/http.ts`؛ استفاده مستقیم از fetch در کامپوننت ممنوع.

## حدود کار
13. فقط همان کاری را انجام بده که در تسک نوشته شده. refactor، تغییر استایل، ارتقای پکیج یا افزودن dependency خارج از تسک ممنوع است (در صورت نیاز، اول بپرس).
14. معماری مقصد: `app/` فقط روتینگ، `features/<name>/{api,hooks,schemas,types,components}`، `shared/` مشترک. وابستگی فقط `app → features → shared`.
15. پایان هر تسک: `pnpm exec tsc --noEmit` و `pnpm lint` بدون خطا، و گزارش به این قالب:
  - فایل‌های ایجاد/تغییر/حذف‌شده
  - هر انحراف از تسک و دلیلش
  - موارد جدید در `BACKEND_GAPS.md`
  - چیزهایی که دیدی ولی عمداً دست نزدی
