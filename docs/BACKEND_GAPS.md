# مستند کسری‌ها و نیازمندی‌های بک‌اند (Backend Gaps)

این سند بر اساس **قانون ۲ قوانین سختگیرانه پروژه** تنظیم شده است.
هر زمان که یک بخش از رابط کاربری (UI) به فیلد یا اندپوینتی نیاز داشته باشد که در `docs/backend-api.md` وجود ندارد:
1. در فرانت‌اند هیچ داده جعلی یا ساختگی تولید نمی‌شود؛ بخش مربوطه با حالت خالی (empty state / "—" / پنهان) رندر می‌شود.
2. نیازمندی در این فایل با فرمت زیر ثبت می‌گردد تا تیم بک‌اند آن را پیاده‌سازی کند.
